# Windows Server Labs

A collection of practical projects focused on Windows Server administration, infrastructure deployment, and security.

This repository documents hands-on laboratory work designed to develop and demonstrate technical skills in managing, configuring, troubleshooting, and securing Windows Server environments.

## Areas of Focus

- Active Directory and Domain Services
- DNS and DHCP
- Group Policy Management
- User and Access Management
- File Server and Permissions
- Server Virtualization
- Public Key Infrastructure (PKI)
- Web Server Administration (IIS)
- Infrastructure Security and Hardening
- Monitoring and Troubleshooting

## Lab Environment

The projects are developed in isolated virtualized laboratory environments using Windows Server technologies and related tools.

## Documentation

Each project is organized in its own directory and includes relevant technical documentation, implementation steps, screenshots, and validation tests where applicable.

## Disclaimer

All activities are conducted in controlled laboratory environments for educational and portfolio purposes.
